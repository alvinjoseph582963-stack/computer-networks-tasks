The 7 Layers of Networking

The OSI model explains how data travels through a network step by step, from an application down to physical signals.

OSI Model

From Layer 7 down to Layer 1.

7

Application Layer

Provides network services to user applications.

HTTP, FTP, DNS
6

Presentation Layer

Handles encryption, formatting, and representation of data.

JPEG, SSL/TLS
5

Session Layer

Starts, manages, and ends communication sessions.

Login sessions
4

Transport Layer

Manages reliable data delivery between devices.

TCP, UDP
3

Network Layer

Helps data travel to the correct destination.

IP
2

Data Link Layer

Handles communication between devices on the local network.

Ethernet, MAC Address
1

Physical Layer

Transmits data as signals through physical media.

Cables, Wi-Fi signals
